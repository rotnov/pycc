## What this change delivers

Issue #892 (milestone v0.4) widened PEP 435 enum support beyond the integer-only
form landed by #379:

- string literal member values on a plain `Enum`;
- `enum.StrEnum`, whose member-value type is fixed to `str` before any member is
  read, so `auto()` there yields the lower-cased member name (CPython semantics);
- `enum.auto()`, newly registered in `pycc_std` as `StdSymbolKind::EnumAutoMarker`
  and recognized inside an enum body by bare name;
- a mixed-value-type enum is rejected in both orderings with a dedicated
  diagnostic, and a non-`str` member of a `StrEnum` gets its own message.

`HirClassDef.enum_members` changed from `Vec<(String, i64)>` to
`Vec<(String, EnumMemberValue)>` (`Int(i64)` / `Str(String)`), threaded through
`pycc_types`, `pycc_mir`, and `pycc_codegen`. Codegen's `emit_enum_member_inits`
now emits `Scalar::Str` for string members via `emit_string_literal`.

Per AGENTS.md "Keep source files decomposable", the enum part of the ~5,446-line
`crates/pycc_hir/src/class.rs` was extracted first, in its own commit, to
`crates/pycc_hir/src/class/enum_class.rs` (class.rs is now ~5,187 lines). Keeping
`lower_enum_class` a standalone extracted function also sidesteps the
cargo-llvm-cov#276 instantiation-merge gap.

## Judgment calls recorded here (D-127)

- **Zero-member enums are reachable** (#744's docstring skip lets
  `class E(Enum): """doc"""` compile), so the member-value type cannot be
  inferred from the members alone. Resolved by defaulting the synthesized
  `value` attribute to `Ty::Int` for a member-less plain `Enum` (preserving
  pre-#892 behavior) and `Ty::Str` for a member-less `StrEnum`, each with a test.
- **`auto()` is matched by bare name inside the enum body**, not through the
  import graph, because a concurrent peer session owns `import.rs`/`module.rs`
  for the #881 series.
- **Enum member equality** (`Color.RED == Color.GREEN`) is still rejected by the
  type checker; that is pre-existing and out of scope here. Filed as **#908**
  in milestone v0.4 before the doc text citing it was written.
