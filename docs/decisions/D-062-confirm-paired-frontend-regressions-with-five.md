## D-062: Confirm paired frontend regressions with five fixed complete replicates

- Status: accepted (active; supersedes D-056 only as the live workflow/comparator authorization while retaining its executable-input classifier and telemetry rule)
- Context: D-056 deterministically removes false failures when every executable input is identical, but deliberately leaves changed-source comparisons on D-051's single predecessor-then-candidate Criterion median. PR #131 measured exact base `619d23291b85418169aded93ae1b58246b3951b1` and head `900bf429ebaee65011ec8b522b2d52f4646ff4b3` at `6752.36 ns -> 6759.24 ns` (`+0.10%`, pass), while its immediate post-merge main run `30201385971` measured the same predecessor and merge commit `62dfc05c97b119c6a9aa8592ccd1e26e8ba1b28d` at `6646.81 ns -> 6889.97 ns` (`+3.66%`, fail). The PR head and merge commit have the identical Git tree `29466decb37627d443d79e18dc18ead7c409e52d`; both runs therefore measured the same changed-source pair, yet reached opposite gate decisions. D-056 would correctly classify that pair as changed and would still expose it to the same single noisy observation. Artifact identity, extraction, predecessor-owned comparator verification, and file checks all succeeded; the remaining defect is changed-source within-run phase, scheduling, and outlier variance.
- Decision: first stage the exact `tests/fixtures/d62-replicated-paired-ci.yml` successor and authorize it alongside active D-056, then activate those reviewed bytes in a fresh-base pull request and retire D-056's live digest. The active workflow retains D-056's complete pre-execution executable-input classifier and deterministic telemetry path: an exact `true` remains non-blocking regardless of timing. For `false`, retain exact predecessor resolution, the benchmark/build contract, separate Cargo target directories, predecessor-first trust order, distinct exact artifact IDs, flattened downloads, the predecessor-owned hash-verified comparator, literal-success `ci-gate` fan-in, and the unchanged greater-than-2% threshold, but replace each revision's single Criterion result with exactly five complete, predeclared runs. The measurement job records every `round-1.json` through `round-5.json`; it uploads and seals all five predecessor files before executing candidate code, then records all five candidate files. The isolated comparator requires exactly those ten regular files with no symlinks or extras, extracts every per-run median, computes the median of each fixed five-value set, and applies the 2% threshold to those aggregates only when inputs changed. No sample is retried, discarded, or added after its result is known.
- Alternatives: rerun a failed workflow until one pair passes (rejected as selection bias); widen the 2% threshold or compare confidence bounds permissively (rejected because it weakens D-044's product invariant); alternate predecessor and candidate executions (rejected because candidate code would run before a later predecessor sample and could influence supposedly trusted evidence through a lingering same-user process); average all runs (rejected because the severe outliers already observed can dominate a mean); use a self-hosted benchmark host (deferred because the repository has no reviewed, available host or operating procedure).
- Consequences: the staging merge changed no live behavior; byte-exact activation makes D-062 current and leaves D-056 as historical audit evidence whose digest the public policy rejects. For changed executable inputs, a fixed majority of three samples, rather than one observation, determines each revision's aggregate while every sample remains auditable for 90 days; identical inputs preserve D-056's logically deterministic non-blocking result. The extra eight Criterion runs add deterministic CI time but remain below the slower Windows matrix leg in local timing. An identical-tree local 5+5 validation retained all results and measured predecessor medians `7068.84, 7046.87, 7033.93, 7093.08, 7100.54 ns` versus candidate medians `7081.96, 7078.49, 7030.96, 7054.06, 7043.53 ns`; aggregate medians were `7068.84 ns -> 7054.06 ns` (`-0.21%`). Synthetic tests prove D-056's identical-input bypass, an isolated extreme outlier cannot decide a changed-input gate, a three-of-five regression above 2% still fails, exactly 2% passes, and missing, extra, symlinked, malformed, non-positive, non-finite, or wrongly shaped evidence fails closed. Activation alone does not resolve #109: issue closure still requires repeated green changed-source PR and post-merge measurements without result selection, because unchanged-source activation runs exercise the telemetry path rather than the blocking aggregate.
