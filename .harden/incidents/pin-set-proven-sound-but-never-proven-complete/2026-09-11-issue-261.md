# Incident: pin-set-proven-sound-but-never-proven-complete (file 1)

**Batch:** `.harden/findings/issue-261.jsonl`, rows 1 and 3 (`fixed` in `cff79ba5`
and `26ec5ca1`). Class size 2 within the batch; no prior topic file.

## Symptom

A rewrite of one skill's normative contract block shipped two normative sentences
that no mechanism held. In the first, the precedence between two terminal states
existed only as the implementation's arm order plus a test comment, and was never
stated in the canonical text an agent reads. In the second, a sentence the plan had
itself named as the guard the rewrite must not drop survived in the prose pinned by
nothing, so it could have been deleted with every gate green while the definition it
qualifies survived. Both were caught at review, rounds 1 and 2.

## Root cause

When a body of contract prose is rewritten, the set of sentences carrying normative
force is re-derived ad hoc rather than reconciled against the set of sentences a
mechanism actually pins. Each pinned phrase is proven load-bearing by a per-phrase
deletion mutation test, so the pin set is proven **sound** — but nothing proves it
**complete**. The two members are the two directions of the same missing
reconciliation: prose with no pin, and mechanism with no prose.

Gap type: content. Batch count: 2. Prior topic files: 0.

## Termination point

belong, but no artefact lands there — see below.
