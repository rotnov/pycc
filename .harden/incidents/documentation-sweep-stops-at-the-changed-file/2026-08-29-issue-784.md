## Symptom

Batch pass over `.harden/findings/issue-784.jsonl` (5 findings, 2 review
rounds). Three findings cluster into one class: prose described a narrower
population than the code covers.

- Round 1: `min_age_lockless` docs (field doc, module-doc clause, match-arm
  comment, `docs/TESTING.md`) named only "pre-Part-4 legacy roots" while the
  sweep's `NotFound` arm also — correctly — covers a Part-4 root killed
  between `create_dir` and lock-file creation.
- Round 2 (two findings): the fix broadened the wording at the enumerated
  sites, and two more instances of the identical narrow phrasing survived —
  one eight lines above a corrected clause in the same doc block
  (`sweep.rs` module doc), one in the new decision entry (D-209).

All were fixed on the branch (`3df0ffac`, `b9f09f77`); the round-2 pair cost
one extra review round.

## Root cause

Two layers. The original narrow claim is this topic's known class: a prose
enumeration of a population, outside the compiler's sight, describing a
subset of what the code handles. The round-2 recurrence has a distinct,
cheaper-to-fix cause: the fix round treated the reviewer's enumerated sites
as the fix's extent instead of deriving the extent from the defect itself —
a repo-wide search for the corrected phrase (`pre-Part-4`) run *before*
committing the round-1 fix would have surfaced all six instances at once
(the same search run after round 2 is what finally proved completeness).

## Termination point

The lexical `precommit` gate this topic's original entry identifies (path
and symbol reference integrity) is *not* the rung for these members: the
stale claims here are semantic ("which population does this floor cover"),
not resolvable by checking that a referenced path or symbol exists. Nothing
mechanical detects the class; the pinned review loop caught every member,
so review remains the right rung — build nothing here.

The enumerated-sites-vs-phrase-extent lesson is process discipline, routed
to the host project's own process journal (`docs/AGENT_RETROSPECTIVE.md`,
2026-08-29 entry) per its own admission bar, in the same change as this
entry.
