# Incident: documentation-sweep-stops-at-the-changed-file (recurrence, file 10)

**Batch:** `.harden/findings/issue-25.jsonl`, row 1 (`fixed`, P2).

## Symptom

Issue #25 asked to move one crate (`pycc_lexer`) out of the delivery plan's
v0.1 "New crates" row. The fix did exactly that and the issue-mandated
sweep (`grep pycc_lexer docs/`) came back clean. The D-068 reviewer then
found that the *same table cell* still listed a second crate
(`pycc_testkit`) that D-018/D-085 deferred and replaced — contradicted by
four later lines of the same file and by `Cargo.toml`'s member list. Same
defect class, same row, missed because the sweep was keyed on the issue's
token rather than on the enumeration being edited.

## Root cause

The sweep's unit was the token named by the issue, not the enumeration the
edit sat in. An enumeration of crates in a "what this milestone adds" row is
a claim about every entry; touching one entry is the moment the others are
cheapest to verify against the tree (here, one `grep members Cargo.toml`).
Batch count: 1. Prior topic files: 9; this is file 10. Gap type: trigger —
the documentation-currency duty fired for the changed token and did not
re-scope to the enclosing enumeration.

## Termination point

Same as the topic's `incident.md`: a decidable reference-integrity gate
would own the general class. This instance is narrower and fully decidable
on its own — every backticked `pycc_*` crate name in a milestone row either
exists in `Cargo.toml` `[workspace] members` or carries an inline deferral
pointer — but that is one table in one document, and a gate that narrow is
review-tier work dressed as a static check.

## Artefact

Build nothing additional, ten files notwithstanding: the topic already
records the promotion (a `precommit` reference-integrity gate) as identified
and deliberately not built inside a triggering pull request, and this
occurrence changes neither the design nor the cost case. Sweep result: after
the fix, `docs/DELIVERY_PLAN.md`'s v0.1 row lists only crates present in
`Cargo.toml` members plus inline-deferred ones; the other milestone rows
name future crates by design and were not swept.
