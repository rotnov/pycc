# Incident: hand-rolled-skip-branch-defies-expect-convention (file 2)

**Batch:** `.harden/findings/issue-1000.jsonl`, row 1 (`fixed` in
`e798d3f3`). Second sighting, cross-language (Python this time; the seed was
Rust).

## Symptom

`changed_decision_files` in `scripts/check_decision_immutability.py` carried
a defensive `R`/`C` rename branch that can never fire because the same
function passes `--no-renames` to `git diff`. Had the flag been dropped, the
branch would have judged the record under the head-side path, which does not
exist at base, and surfaced a `PlumbingError` instead of a violation.

## Root cause

Same as the seed: a defensive branch written for a state the code's own
construction rules out, unreachable by real input and therefore untested,
hiding a wrong behaviour behind a "just in case" comment. The seed's lesson —
do not write the branch; if the state is impossible, make its impossibility
the assertion — was applied by the fix, which keeps only the token-stream
realignment and lets the record fall into the fail-closed unexpected-status
path.
