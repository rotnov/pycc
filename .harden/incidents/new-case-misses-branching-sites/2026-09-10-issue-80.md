## Symptom

Two sibling rejection arms — a suffix rule and a directory-component rule —
were normalized asymmetrically: the suffix arm case-folded, the directory arm
compared exact bytes, so `__PYCACHE__/x` fell to the generic hash backstop
instead of the by-name rejection. The round-1 repair symmetrized the code and
added a wrong-case mutation test for the arm just fixed only; round 2 had to
add the symmetric suffix test.

## Root cause

The plan lists both arms as siblings and is silent on case policy; the
implementer normalized one. The repair then scoped itself to the site just
reported — the pattern this topic's `incident.md` names: "a repair is itself
scoped to the site that was just found missing, so the same omission
reproduces for every site still missing". Gap type: row 2 content (plan
silent), row 5 compliance-shaped recurrence. Batch count: 2. Prior topic
files: 4 (`incident.md` + recurrences 3, 4); this is file 5.

## Termination point

`SKILL_PAYLOAD_REJECTED_SUFFIXES × SKILL_PAYLOAD_REJECTED_DIRECTORIES ×
case-variant` covers both arms by construction and cannot be extended one
site at a time.

## Artefact
