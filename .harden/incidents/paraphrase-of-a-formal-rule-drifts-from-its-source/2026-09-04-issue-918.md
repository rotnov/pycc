# Incident: paraphrase-of-a-formal-rule-drifts-from-its-source (recurrence 2)

**Batch:** `.harden/findings/issue-918.jsonl`, class A (3 findings across 4 rounds).

## Symptom

A rule introduced by this change's *own* decision record — "a parameterized
container annotation is rejected in a protocol member" — was restated across six
files and was wrong in every one of them. The rule as implemented gates protocol
**attributes** only; a protocol *method*'s parameter lowers a container
normally and was reproduced compiling and running end to end.

Affected replicas, derived from `git diff fe1e9806~1..e7fe78f7` rather than from
memory -- six files carrying eight statements: `crates/pycc_diag/src/explain.rs`,
`crates/pycc_hir/src/class/protocol.rs`, `crates/pycc_hir/src/func.rs` (two),
`docs/PYTHON_STANDARDS.md`, `docs/TYPE_SYSTEM.md`, and the D-227/D-228 decision
record (two). Two opposite over-claims appear across them -- "containers lower in
protocol-member positions" and "a protocol member's type gets `C0001`" -- and both
are wrong for the same reason: they say *member* where the gate says *attribute*.
`crates/pycc_hir/src/tests.rs` echoed the wording at four further sites, but a
test asserting the message is not an independent statement of the rule.

## Root cause

**Gap type: content.** The rule was authored in prose and then copied, so the
authoritative statement is not any one of the six files — it is the code. The
R1 -> R3 cascade is the diagnostic detail that matters: round 1's fix aligned
the replicas *to each other* rather than to `lower_protocol_class`, which
manufactured false agreement and made rounds 2 and 3 harder, not easier. Six
mutually-consistent wrong sentences read as verified.

This recurrence was **pre-registered**: `2026-09-02-issue-868.md`'s Proof clause
named "the next pull request that adds a decision record with a numbered rule"
as its measurement. This is that pull request, and the rule shipped there did
not prevent the class.

## Termination point

The rule shipped by the #868 entry (quote the formal rule, do not paraphrase it).
It existed, it was in scope, and the failure occurred anyway.
