# Incident: own-change-falsifies-adjacent-prose (recurrence 4, fifth file)

**Batch:** `.harden/findings/issue-795.jsonl`, rows 1 and 2 (rounds 1 and 2).

## What happened

Two members, both prose that was true before the #795 diff and false after it,
neither of them prose the diff was editing:

- Round 1, `docs/PYTHON_STANDARDS.md:236`. Rule 12's closing sentence read
  "All are `core` gaps" about the manifest rows it summarizes. The same commit
  reclassified one of those rows to `out-of-scope`, so the summary contradicted
  the table it summarizes. This is also the shape recorded once under
  `summary-tier-contradicts-its-own-body`.
- Round 2, `tests/issue_542_except_star.rs:872`. A rationale comment described
  the three fixtures above it as intercepting a `return` from the *try* or
  *handler* body. The diff made a handler-origin `return` a compile error and
  therefore moved all three returns into the try body, so half the disjunction
  became unreachable.

Both were fixed inside the review loop, comment- and sentence-only, one round
each.

## Why it was not caught

Same cause as the four earlier files: the falsified sentence is not in the
diff's own edit set, and its falsity is semantic. A summary sentence saying
"all" is true or false only relative to a table elsewhere in the file; a
comment saying "try/handler" is true or false only relative to what the
compiler now accepts. Gap type: **content** at the review rung, not trigger —
the reviewer's doc-drift item fired and found both, in the first round each
became visible.

## Artefact and why this type

Build nothing, unchanged from the counter-3 and counter-4 escalation checks
recorded in this topic. Walking the ladder again for these two members:

- **Static/precommit:** not decidable. Nothing reads "All are `core` gaps"
  and resolves it against a JSON manifest's `category` fields two files away,
  and nothing distinguishes a stale `try`/`handler` disjunction from a correct
  one. A checker that flagged every quantifier adjacent to a changed table
  would fire on every doc change in the repository.
- **Textual:** disqualified by this topic's own count — five files now, and a
  text that has failed three times fails a fourth.
- **Seam:** no tool-call fact separates "edited a table" from "edited a table
  whose summary sentence is now wrong".
- **Review:** caught both members at note/warning severity, cost two one-line
  edits and no re-work. It is the terminal rung for this class.

The counter is the artefact.
