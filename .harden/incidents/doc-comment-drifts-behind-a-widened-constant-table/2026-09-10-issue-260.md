# Incident: doc-comment-drifts-behind-a-widened-constant-table (file 2)

**Batch:** `.harden/findings/issue-260.jsonl`, row 1 (`fixed` in `6f93b1ba`).

## Symptom

New prose in `docs/AGENT_TOOLING.md` wrote "(seven at the time of writing)"
next to `ALPHA_EVAL_RUNNERS` — the pre-drift form of the seed incident, in
the very change whose purpose was to stop a hard-coded skill set from
drifting behind that table. Caught at round-1 review.

## Root cause

A prose count of a constant table has no mechanical link to the table; it is
correct on the day it is written and wrong the first time the table widens.
Gap type: absence (no static rung existed). Batch count: 1. Prior topic
files: 1 (seed, #739, whose entry said a second occurrence should escalate).

## Termination point

`scripts/validate_agent_assets.py` — it already reads `docs/AGENT_TOOLING.md`
in `validate_skill_lock`, so the count-vs-table check lives beside the table
it guards and runs in required CI for every agent and human.

## Artefact

Rung: static (`precommit`/CI). Count-equals-table rather than
count-forbidden: the document legitimately says "all seven alpha skills"
twice today, so an equality check is green now and turns the actual defect
(table widens, prose stays) into a red merge gate. Rule: a numeral within
40 characters before "alpha skill(s)" (excluding bound phrases such as "at
least"), or a numeral immediately followed by skill/alpha/project-local/"at
the time of writing" in a sentence that names `ALPHA_EVAL_RUNNERS`, must
equal `len(ALPHA_EVAL_RUNNERS)`. Known limit: sentences are approximated per
line, so a count whose table mention sits on a later line is not checked.

Sweep result: the tracked document has exactly three legitimate matches
(lines 245, 247 and 253), all equal to the table length. Round 3 of the
review found the guard is per-line: a count whose anchor phrase sits on the
next line is invisible to it. The document's claim was narrowed to that
same-line condition and the one such passage was reflowed; the guard itself
was left per-line on purpose — a cross-line sentence model would have to
parse Markdown, which is a larger artefact than this class justifies.

## Fixture

None — static gate proven by the violator/clean runs in the frontmatter.
