# Incident: a plan-mandated deliverable that is not code was not delivered

**Batch:** `.harden/findings/issue-918.jsonl`, class F.

## Symptom

The published plan for #918 Part 1 enumerated, alongside its code changes, a
regression test pinning the ellipsis-before-arity check order for `tuple[...]` —
the ordering is load-bearing, because `tuple[int, ...]` has a legal arity of 2
and an arity check alone accepts it, silently lowering
`tuple[int, EllipsisType]`. Every code change the plan specified was
implemented. The named test was not written; the gap was found later at
`crates/pycc_types/src/tests.rs:9868` and added.

## Root cause

**Gap type: compliance.** AGENTS.md's Completion check item 6 already covers
this case by name: "A plan's own enumerated non-code deliverables are a list of
this kind: a clause directing that a follow-up issue be filed, a measurement be
recorded, or a named document be updated is an item to track, not prose
accompanying the code changes. Implementing every code change a plan specifies
does not discharge the clauses that specify something other than code."

The rule is unambiguous, in scope, and was not followed. The mechanism that
allowed it: the plan's todo list was seeded from the plan's *code* work items,
so the non-code clause never became a trackable entry — and item 6's own guard
("the todo list is the guard") only works if the list is built before the first
item is started.

## Termination point

AGENTS.md Completion check item 6.

## Artefact

**None — build nothing, deliberately.**

`references/rule-audit.md` is explicit that a compliance gap cannot be fixed
with text: the rule was clear and was ignored, so a clearer rule changes
nothing. Rewording item 6, or adding an item 7 restating it, is the failure mode
the audit exists to block.

What this entry ships instead is the measurement: item 6 is now recorded as
**measured at one failure**. A second occurrence promotes the class to a
mechanical rung — the natural one being that the plan's own enumerated
deliverables are extracted into the todo list by the tool that reads the plan,
rather than transcribed by the agent that read it.
