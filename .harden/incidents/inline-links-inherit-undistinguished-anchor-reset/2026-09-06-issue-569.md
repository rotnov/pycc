## What happened

The first independent implementation review of #569 found that 19 new
source-evaluation and related-evidence links inherited the global anchor reset
and looked like surrounding prose. This is one finding with one shared cause,
not 19 incidents. The second full review was clean after the focused fix.

## Why it was not caught

The existing rendered checks measured geometry, keyboard access, contrast and
motion, but not whether these text links remained visually distinguishable.
The batch trace found no matching journal incident; focus/scroll ownership and
missing independent mutation cases are different classes.

## Artefact and why this type

Build nothing additional. The implementation fix in `site/styles.css` already
adds scoped underlines, and `scripts/check_site_reduced_motion.js` now tests
computed underlines in both motion modes with expected-scope zero-match guards.
No supported governance or skill defect warrants a new rule, hook or arena run.
`pending` seeds the recurrence counter; it does not mean the UI defect is unfixed.
The host postmortem admission check excludes this ordinary UI/test defect.

## Proof

Before the fix, all 19 links computed `text-decoration-line: none`; the browser
regression exited 1 with 14 expected failures (seven pages, two motion modes).
After the fix, all 19 links were underlined and the same evaluator exited 0.
The final seven-page accessibility gate also passed. The finding and scoped
fix-content reference are retained in `.harden/findings/issue-569.jsonl`.
This is a browser regression, not a static CSS proof or universal accessibility
guarantee. No new harden artefact or arena result is claimed.
