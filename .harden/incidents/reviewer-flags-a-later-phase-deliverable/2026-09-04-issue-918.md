## Symptom

A review round flagged the absent `docs/sessions/` handoff file as a
completeness gap of the diff. It is written after the review loop, in the pull
request that delivers the work — by construction it cannot exist when the loop
runs. Refuted at the cost of one verification step.

## Root cause

**Gap type: compliance.** This was the open question the batch tracer could not
settle from the filesystem, and it is settled here from the orchestrating
session's own transcript.

`2026-09-02-issue-868.md` shipped
`.claude/skills/issue-implement/references/review-brief.md`, whose fixed
paragraphs exclude `docs/sessions/`, the pull-request body, the findings pile,
and gate/GitHub/`git` claims from review scope; `issue-implement/SKILL.md:376`
instructs "Compose the brief from references/review-brief.md ... do not retype
the exclusions from memory". The discriminator was whether round 1's brief was
actually composed from that template — content gap if it was, compliance gap if
it was not.

Grepping this session's transcript for `review-brief` returns hits only from
2026-09-02 (the #868 session that authored the template) and from today's
tracer report itself. **The template was never read or cited during the #918
review dispatch.** The brief was typed freehand, which is exactly what the #868
artefact was built to stop, and which `SKILL.md:376` names as the thing not to
do.

That resolves the branch `2026-09-02-issue-868.md` pre-registered: occurrence 4
means the template was not used.

## Termination point

`.claude/skills/issue-implement/SKILL.md:376` — the pointer at the template. It
exists, it is unambiguous, and it was not followed.

## Artefact

**None — build nothing, deliberately.**

Two independent reasons converge. First, `references/rule-audit.md` disqualifies
a textual artefact outright at three or more files in one topic; this is the
fourth, so a fifth rewording is off the table by rule. Second, a compliance gap

The mechanical rung this class now points at is unambiguous and is recorded here

exclusion paragraphs cannot be omitted because they are never retyped. That is
outside this change's scope and is not started on the strength of a refuted
finding: the cost of this class is one wasted verification step per occurrence,
never an incorrect merge, so it fails AGENTS.md's filing bar for process
observations the same way class D does and belongs in the retrospective, not the
