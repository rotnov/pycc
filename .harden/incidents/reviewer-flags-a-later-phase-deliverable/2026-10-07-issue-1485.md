# Incident: reviewer-flags-a-later-phase-deliverable (issue #1485 batch)

**Batch:** `.harden/findings/issue-1485.jsonl`, row 4 (`refuted`).

## What happened

In round 1 the reviewer reported that the `#[ignore]`d embedded success test had no
local run evidence. Running that test is a CI result: the include-ignored legs run it.
The review-brief template already lists gate results as out of scope. The reviewer
treated the absence of a local run as a finding, even though no relocatable CPython
3.14 is available locally. The orchestrator refuted it, and rounds 2 and 3 did not
repeat it.

## Artefact

the case in later rounds. This entry is a counter: if the pattern recurs, the brief
template (`.claude/skills/issue-implement/references/review-brief.md`) should name
