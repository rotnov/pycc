- **One question per turn.** The answer to the first often changes how the second
  should be worded, so asking both at once wastes the second.
- **Give options with a recommendation** — answering must be cheaper than reading.
- **A counter-proposal wins**; record it as the decision, not as a variant.
- **Record the decision in the same turn**, in `docs/decisions/` if it is hard to
  reverse. Never re-ask what the history already answers.
