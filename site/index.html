pycc is an open-source ahead-of-time compiler project for standard Python 3.14. Its design contract is to check annotations at compile time, then emit a fast, standalone executable—without inventing a new language. AI agents create the entire project; a human only manages direction, priorities, and constraints.

02 · Why pycc

One tool should finish the whole job.

Type checkers stop before runtime. Packagers bundle an interpreter. Python-like compilers ask you to adopt a dialect.

pycc's design target combines hard type errors, standard Python syntax, and a native executable in one compiler pipeline. Annotations are the contract—not optional hints.
